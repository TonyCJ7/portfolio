## `src/content/jsonLd.ts`

## Constants

- [`current`](../../../../../src/content/jsonLd.ts#L7): the first experience row, Tony's current job, which names the employer in `worksFor`.
- [`personJsonLd`](../../../../../src/content/jsonLd.ts#L9): the schema.org `Person` the home page prints as JSON-LD, so search and AI engines read Tony's name, title, employer, Dubai address, email, GitHub and LinkedIn pages, every skill and the site URL as facts. Every value comes from the content files and `siteUrl`, except the address, which is fixed to Dubai, `AE`. The phone number is left out.
