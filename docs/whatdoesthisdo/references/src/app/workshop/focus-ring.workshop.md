## `src/app/workshop/focus-ring.workshop.tsx`

## Constants

- [`TARGET_CLASS`](../../../../../../src/app/workshop/focus-ring.workshop.tsx#L3): the token classes shared by the three sample controls, so only the ring differs between them.
- [`entry`](../../../../../../src/app/workshop/focus-ring.workshop.tsx#L5): the Focus ring Workshop entry: a `target` select (button, link, input) and a `state` select (rest, focus, focus by default) that makes the frame force the ring through `data-state="focus"`. Its spec names the ring colour `--focus-ring`, Tangerine in dark and Tangerine Text in light, and the `main:focus-visible` exception.
