## `src/app/page.tsx`

### [Home()](../../../../../src/app/page.tsx#L3)

Renders the placeholder home page shown until the designed portfolio page is built: the logo with the name in a header, a role line with the tangerine dot, a headline, and a button to Tony's GitHub profile.

- Out: the page markup, styled only with the tokens from `globals.css` (`text-display`, `text-fg-2`, `bg-accent`); ground and text colour come from the `html` element. The button uses ink text on tangerine so the label reaches 5.8:1 contrast, and turns to the accent text colour on hover.
