## `src/components/Link/Link.workshop.tsx`

## Constants

- [`DEFAULT_TEXT`](../../../../../../src/components/Link/Link.workshop.tsx#L10): the link text each kind shows when the Text control is empty.
- [`HREF`](../../../../../../src/components/Link/Link.workshop.tsx#L17): the `href` each kind shows in the scene and in the usage line.
- [`entry`](../../../../../../src/components/Link/Link.workshop.tsx#L24): the Link Workshop entry: a kind select, a state select and a text control of up to 40 characters. The prose kind renders inside a short sample sentence; the other kinds render alone. Prose and social links get `external`, so the usage line shows it.
