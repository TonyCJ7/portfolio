## `src/components/SkillGroup/SkillGroup.workshop.tsx`

### [groupsFor(name)](../../../../../../src/components/SkillGroup/SkillGroup.workshop.tsx#L5)

Turns the Group control into the groups the scene's `SkillTable` shows.

- In: `name`, the control's value: `"all"` or the name of one skill group.
- Out: every skill group for `"all"`. Otherwise a list holding only the group with that name, so the table still draws its top and bottom hairlines.

## Constants

- [`entry`](../../../../../../src/components/SkillGroup/SkillGroup.workshop.tsx#L13): the Skill group Workshop entry: one Group control, rendered as a `SkillTable` of every group or of one, not centered in the frame.
