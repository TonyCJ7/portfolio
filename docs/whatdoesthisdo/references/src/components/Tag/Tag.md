Describes the props of `Tag`.

- `children`: the name shown in the pill.

### [Tag(props)](../../../../../../src/components/Tag/Tag.tsx#L7)

Renders one small pill naming a tool or technology, as a list item.

- In: `children`, the name shown in the pill.
- Out: an `li` with the Tangerine Soft fill, Tangerine Text colour, full radius and the small type step. Long names wrap inside the pill instead of clipping. It belongs inside a `ul`; `TagList` is the usual parent.
