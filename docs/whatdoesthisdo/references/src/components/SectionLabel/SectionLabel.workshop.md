## `src/components/SectionLabel/SectionLabel.workshop.tsx`

## Constants

- [`PLACEHOLDER_PARAGRAPHS`](../../../../../../src/components/SectionLabel/SectionLabel.workshop.tsx#L4): neutral filler paragraphs about the layout. The desktop scene shows the first one under the label. The phone scene shows all of them, so the scroll area is tall enough to scroll.
- [`entry`](../../../../../../src/components/SectionLabel/SectionLabel.workshop.tsx#L14): the Section label Workshop entry with one text control of up to 11 characters, "Experience" by default. On desktop it renders the label above one paragraph. On a phone it renders a 480 px tall scroll area, so the sticky bar can be checked.
