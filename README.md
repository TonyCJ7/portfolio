# Tony Cherian Jacob · portfolio

Personal portfolio of Tony Cherian Jacob, frontend developer. Built with Next.js, React and Tailwind CSS.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates the production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.

## Layout

- `src/app` holds the App Router pages, the global stylesheet, the web manifest and the icon files Next.js serves.
- `src/components` holds the React components, one folder per component.
- `public/icons` holds the manifest icons.
- `docs/whatdoesthisdo` holds the reference pages shown by the WhatDoesThisDo editor extension.

The logo masters live in `design/logo`, which is kept out of git.
